# Chenbot 水平测试与自适应学习（开发预览，未上线）

## 目标
当前英语题库共有 214 道未经真实用户标定的手写题，其中字幕词形排名前 50,000 的 175 题参与 12 道自适应选择题。结果只能作为等级参考范围；未能支持单一等级时不会覆盖原有识图偏好。词频与词汇量的差异、可复现的交叉统计和算法限制见 `docs/vocabulary-assessment-research.md`。

## 英语暂定分档（待标定）
用户指定的数值都是分档下界：文盲 0–1,999、菜鸡 2,000–7,999、青铜 8,000–14,999、白银 15,000–19,999、黄金 20,000–29,999、钻石 30,000–49,999、莎士比亚 50,000 及以上。原“呆子”并入“菜鸡”，旧偏好迁移时保留原值。它们是产品自定义边界，不是已有测量结论。应先定义词条、词族及变形统计方法，再使用有代表性的校准题库与独立样本估计误差。未经校准不能把档位的数字范围展示为用户的测量结果或自称精准；达到测试上限时提示需要更多题目验证，不声称用户掌握 50,000 词。

测试使用题目精确词形排名、未标定的答对模型和 25% 的四选一猜测假设，依据回答选择下一题，并给出模型参考范围。“不认识”和选错均作为一次未答对，不额外加重权重。仅在模型范围落在单一等级且存在双侧证据时暂存推荐；达到题库上限、范围过宽或答题表现明显不符合频率顺序假设时，不自动覆盖原等级。用户可在识图按钮旁自行切换。推断模型和机械交叉表不代表个人已掌握词汇量，详见 `docs/vocabulary-assessment-research.md`。旧版其他分级标准的保存值保留在本机，不自动等同于新等级。

## 日语
参考 JLPT N5–N1 对知识范围划分，但 JLPT 本身不公布官方词汇量阈值；日语等级映射尚未完成，须校准验证。题库需考虑汉字、假名、义项、多读音；不要把日语映射伪装为官方 JLPT 成绩。

## 题目与学习
- 每题四个选项与“不认识”，干扰项需质量审核，答案和题目顺序随机化，不能泄露可预测规律。
- 题目有语言、词条、义项、难度、来源、许可、版本和校准状态；注册初测的题库只能选择已审核、标定的题目。
- 根据先前答案选择下一个未答题；早期分散覆盖难度，避免连续偏高或偏低。记录跳题、答错、猜测可能性与响应不确定性；选题和最终测量都必须经离线仿真、分层验证、偏差与重测评估。
- 每个账号每种语言单独保存评估版本、估算区间、置信度、最近活动、题目历史；不能以本地数据作为付费或权益的权威来源。无网络或资料不足时允许稍后测试，不向用户编造结果。
- 识图结果的词优先按当前水平排序，并提供已认识／太难反馈；重复间隔练习综合答对、遗忘和用户选择，不因一题变化整个等级。
- 初测答案、语言和水平属于学习数据；说明用途，支持导出和删除，避免收集不必要的图片与个人信息。记录条款版本和结果模型版本。

## 上线门槛
当前没有经过标定的大规模题库、已验证的词汇量区间、日语分级、真实注册后自动测试或线上自适应推荐；不得对外声称正式评测已完成。先建立带许可证的题库、评测服务、可复现校准集与质量标准，再启动小规模自愿内测。
