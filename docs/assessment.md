# Chenbot 水平测试与自适应学习（设计中，未上线）

## 目标
注册后按学习语言进行初测，通过选择题、逐步选题与后续复习估计用户水平。所有结果显示为估算范围，用户可调整；不可把学习者的答题数直接宣传成真实词汇量。用户可以选择“不认识”，避免被迫猜测；评测允许暂停和重新测试，使用保护机制避免重复答题造成虚假提升。

## 英语暂定分档（待标定）
用户明确要求 S 为 20,000 词以上。以下其余边界仅为产品工作假设，不是已有测量结论：H 0–999、G 1,000–1,999、F 2,000–2,999、E 3,000–4,999、D 5,000–6,999、C 7,000–9,999、B 10,000–14,999、A 15,000–19,999、S 20,000+。应先定义词条、词族及变形统计方法，再使用有代表性的校准题库与独立样本估计误差。未经校准不展示数字范围或自称精准；达到测试上限时用“可能达到上限，需更多题目验证”，不声称用户掌握 20,000 词。

## 日语
参考 JLPT N5–N1 对知识范围划分并映射九档，但 JLPT 本身不公布官方词汇量阈值；S–H 与 JLPT 的映射属于产品估算，须校准验证。题库需考虑汉字、假名、义项、多读音；不要把日语映射伪装为官方 JLPT 成绩。

## 题目与学习
- 每题四个选项与“不认识”，干扰项需质量审核，答案和题目顺序随机化，不能泄露可预测规律。
- 题目有语言、词条、义项、难度、来源、许可、版本和校准状态；注册初测的题库只能选择已审核、标定的题目。
- 根据先前答案选择下一个未答题；早期分散覆盖难度，避免连续偏高或偏低。记录跳题、答错、猜测可能性与响应不确定性；选题和最终测量都必须经离线仿真、分层验证、偏差与重测评估。
- 每个账号每种语言单独保存评估版本、估算区间、置信度、最近活动、题目历史；不能以本地数据作为付费或权益的权威来源。无网络或资料不足时允许稍后测试，不向用户编造结果。
- 识图结果的词优先按当前水平排序，并提供已认识／太难反馈；重复间隔练习综合答对、遗忘和用户选择，不因一题变化整个等级。
- 初测答案、语言和水平属于学习数据；说明用途，支持导出和删除，避免收集不必要的图片与个人信息。记录条款版本和结果模型版本。

## 上线门槛
当前没有经过标定的大规模题库、持久化的分语言水平、真实注册后强制流程、有效区间或线上自适应推荐；不得对外声称功能已完成。先建立带许可证的题库、评测服务、可复现校准集与质量标准，再启动小规模自愿内测。
