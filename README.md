# Chenbot

Flutter 安卓／iOS 学习应用，当前为开发预览，不能用于正式运营或收款。支持英日切换、选择或拍摄照片并在本机预览、批量卡片、示例词条和系统发音。批量识图只在显式配置开发桥接后可用，尚非正式服务。示例收藏保存在本机，暂不支持账号同步。

## 运行

先安装与 `pubspec.yaml` 中 Dart SDK 约束兼容的 Flutter、Android SDK，以及开发 iOS 所需的 Xcode。将 Flutter 加入 PATH，在本目录运行 `flutter pub get`、`flutter test`、`flutter run`。连接 Android 真机时可用 `flutter devices` 查看设备，再运行 `flutter run -d <设备 ID>`。本机的 `.vscode/settings.json` 和 `android/local.properties` 不纳入版本管理；在其他电脑上需按当地 SDK 安装位置配置。Android 和 iOS 的 `com.example` 标识符是临时值，发布前必须更换。

邮箱 OTP 使用 Supabase Flutter SDK。只有配置 `--dart-define=SUPABASE_URL=...` 和 `--dart-define=SUPABASE_ANON_KEY=...` 才显示登录流程。该 key 必须是客户端可公开的 publishable/anon key，绝不使用 service role key。邮件模板必须配置发送数字验证码；需配置正式邮件服务、发送限制、验证码防滥用、隐私政策及删除账户能力。未经真实服务与设备测试，不得公开上线。

## 未完成的关键功能

注册测评与自适应分档的安全设计见 `docs/assessment.md`；目前仅有选题算法草案，没有经标定题库或可信词汇量估算。

- 正式的照片识别尚未接入；仅配置开发参数后可经本机桥接测试 DeepSeek。`server/vision.mjs` 是服务端视觉适配器，非 Web 服务、不提供身份认证或额度控制；已做少量真实模型格式测试，但没有部署或进行全面评估。不得将它直接暴露公网。
- 账号的在线登录流程有代码，但尚未绑定项目、邮件供应商或验证服务；示例收藏、批量识别词条及其收藏已存于本机；跨设备同步尚未实现。
- 额度、真实购买、购买验签、恢复、退款、对账、账户绑定、反重复和客户支持均尚未实现；充值入口被禁用，不能收费。
- AI 的识别准确率、边界框、日语读音、权限行为和照片清理策略均需真机测试。照片可能含有个人信息；正式上线前需要明确取得适当授权、区域处理方式和删除策略。

## 模型选型

按用户要求优先使用 DeepSeek `deepseek-flash` 视觉模型，已使用少量公开与程序生成测试图片验证返回格式。真实应用还需配置服务端 API Key，并继续评估区域可用性、费用、数据处理、定位准确率与中日英词汇质量。适配器亦可配置其他 OpenAI 兼容视觉接口。`server/vision.mjs` 返回规范化 0–1 边界框；客户端在保存或上传前将 JPEG/PNG 解码、应用方向并重新编码以移除 EXIF；生产服务仍须独立执行输入解码、尺寸限制、元数据处理和验证，且定位精度需要进一步测试。

测试模型适配器：`node --test server/vision.test.mjs`（Node.js 需要支持内建 test runner）。

## 本机识图开发桥接（仅供开发）

`server/dev-server.mjs` 只绑定 127.0.0.1，供开发者本机试验模型，不含账号、额度或支付。禁止公网部署、禁止用于真实用户。需在本机进程环境中设置 `DEEPSEEK_API_KEY` 和至少 24 字符的随机 `CHENBOT_DEV_TOKEN`，启动 `node server/dev-server.mjs`。请勿把 API Key 写入代码、命令历史或客户端构建参数。调试构建可通过 `--dart-define=CHENBOT_DEV_TOKEN=<相同的随机令牌>` 连接；Android 真机通过 USB 执行 `adb reverse tcp:3218 tcp:3218`。应用仅允许连接本机 HTTP 地址，且发布构建中禁用此功能。真实用户产品必须替换为带认证、额度事务与滥用防护的服务端。

## 批量照片和本机数据

开发预览中可批量选择照片，压缩并移除 EXIF 后写入应用私有目录；配置开发桥接时逐张发送模型，失败项可重试。每个结果生成可上下滚动的单词卡，左滑下一条，右滑打开收藏或丢弃操作；丢弃只隐藏该卡，原照片保留。收藏词条单独保存在本机文件中。当前没有账号同步、导出或清理入口；应用数据可能包含在设备系统备份中，卸载或清除数据可能导致丢失。正式上线前需实现数据管理、迁移与隐私说明，不能承诺绝对不离开设备（用户主动识图时图片会发送到 AI 服务）。

## 已验证的开发基线

2026-11-09 已在 Pixel 11（Android 17）进行一轮调试验证：安装启动、英文及日语真实识图、纯色图片的形容词回退、系统发音完成回调、左右滑动、收藏与丢弃、冷启动后本机数据保留。已修复重启后学习语言选择丢失的问题。`flutter analyze` 无问题，Flutter 测试 16 项通过（需要显式配置本机服务的测试默认跳过），服务端单元测试 7 项通过。这是开发冒烟测试，不代表已具备上线条件。

## 版本管理

每个独立功能或修复单独提交，并在测试后推送到私有仓库。代码、项目配置与依赖锁文件纳入版本管理；API 密钥、签名文件、本机 SDK 路径、编译产物和用户照片不提交。`.gitignore` 不会阻止把密钥直接写进源代码，提交前仍需检查改动。
