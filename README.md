# Chenbot

Flutter 安卓／iOS 学习应用，当前为开发预览，不能用于正式运营或收款。支持英日切换、选择或拍摄照片并在本机预览、批量卡片和系统发音。用户可输入自己的 DeepSeek API Key，在确认后直接从设备发送照片识图。识词收藏保存在本机，暂不支持账号同步。

“阅读”页面提供《南京条约》和阿波罗 11 号事故预备讲话的英文原文与历史图片。长按文章中的英文词可离线查看词义、原文例句和系统发音；文本、图片、词典来源及限制见 `docs/reading-sources.md`。

界面的英文默认字体在 iOS 使用系统 Georgia；Android 使用与 Georgia 字宽兼容的开源 Gelasio。Gelasio 来自 [SorkinType/Gelasio](https://github.com/SorkinType/Gelasio)，使用 SIL Open Font License 1.1，许可文本随应用提供。若以后需要在 Android 分发原版 Georgia，需要提供适用于应用分发的字体授权。

## 运行

先安装与 `pubspec.yaml` 中 Dart SDK 约束兼容的 Flutter、Android SDK，以及开发 iOS 所需的 Xcode。将 Flutter 加入 PATH，在本目录运行 `flutter pub get`、`flutter test`、`flutter run`。连接 Android 真机时可用 `flutter devices` 查看设备，再运行 `flutter run -d <设备 ID>`。本机的 `.vscode/settings.json` 和 `android/local.properties` 不纳入版本管理；在其他电脑上需按当地 SDK 安装位置配置。Android 和 iOS 的 `com.example` 标识符是临时值，发布前必须更换。

真机集成测试应优先使用模拟器或专用测试机，并事先备份应用数据。`flutter test` 默认会在集成测试结束时卸载目标应用，卸载会清除应用本地数据；如需保留测试应用，使用 `flutter test --no-uninstall`。使用隔离测试包时，应从干净的构建目录生成并核对 APK 包名，不能复制旧构建缓存或对含用户数据的应用执行卸载、清除数据等测试操作。

邮箱 OTP 使用 Supabase Flutter SDK。只有配置 `--dart-define=SUPABASE_URL=...` 和 `--dart-define=SUPABASE_ANON_KEY=...` 才显示登录流程。该 key 必须是客户端可公开的 publishable/anon key，绝不使用 service role key。邮件模板必须配置发送数字验证码；需配置正式邮件服务、发送限制、验证码防滥用、隐私政策及删除账户能力。未经真实服务与设备测试，不得公开上线。

- 额度、真实购买、购买验签、恢复、退款、对账、账户绑定、反重复和客户支持均尚未实现；充值入口被禁用，不能收费。
- AI 的识别准确率、边界框、日语读音、权限行为和照片清理策略均需真机测试。照片可能含有个人信息；正式上线前需要明确取得适当授权、区域处理方式和删除策略。

## 模型选型

按用户要求使用 DeepSeek `deepseek-flash` 视觉模型。用户在“我的 → DeepSeek 识图设置”中自行输入密钥，密钥使用设备安全存储，按本机用户区分，不进入项目代码、构建参数或 Chenbot 服务器；Android 排除密钥备份，iOS 使用仅限本机的 Keychain 项。单张和批量识别需用户逐次确认，照片经 HTTPS 发送至 DeepSeek，可能产生 API 费用；超时后重试也可能收费。调用启用 DeepSeek 基础内容安全检查。需继续评估区域可用性、费用、数据处理、识别准确率和日语读音。客户端在保存或上传前将图片解码、应用方向并重新编码以移除 EXIF，模型返回规范化边界框；识别结果可能不准确。

根据用户要求，设置页会在本机直接显示完整密钥，可手动隐藏；不要公开截图。页面通过 DeepSeek 官方余额接口查询当前余额；本机只累计此功能启用后、当前本地用户收到用量信息的请求 Token，可能遗漏失败请求、其他设备和过去的调用，也不能替代账户账单。账户历史消费金额请在 DeepSeek 控制台查看。

测试模型适配器：`node --test server/vision.test.mjs`（Node.js 需要支持内建 test runner）。

## 本机识图开发桥接（仅供开发）

`server/dev-server.mjs` 是保留的旧测试工具，当前应用界面使用用户密钥直接连接 DeepSeek，不需要启动此桥接。该工具只绑定 127.0.0.1，不含账号、额度或支付；禁止公网部署。请勿把 API Key 写入代码、命令历史或客户端构建参数。

## 批量照片和本机数据

开发预览中可批量选择照片，压缩并移除 EXIF 后写入应用私有目录；用户确认后逐张发送 DeepSeek，失败项可重试。每个结果生成可上下滚动的单词卡，左滑下一条，右滑打开收藏或丢弃操作；单词可点击收藏、直接拖动调整标签位置或拖入垃圾桶，半透明连线连接物品与标签；位置保存在本机。已记录的词形会在后续识图中本机过滤，可恢复误丢的词。原照片和收藏不会因此被删除。单张和批量识别结果都保存在本机。英语结果只显示本地词频表中、与所选等级相同或高一级的词；词形排位除以五是未标定的试用换算，不代表准确难度。每张图请求最多 32 个候选，允许清晰可见的物品部件和准确的不同名称；无合适物品时允许少于 32 个。相同位置的重复词会合并，个别格式无效的候选不会使其余结果失效。当英语候选都不符合等级或不在词表中时，最多额外请求一次，告知模型目标范围和已识别词的本地排名；返回结果仍由本机逐词核验。垃圾桶过滤完全部物品也可能重试，两种重试共用每张照片最多三次请求的上限；每次都可能产生费用。模型只应返回照片中清晰可命名的物品名词；若没有合适物品则返回空结果。词形覆盖和日语识别均不保证完整。当前没有账号同步、导出或清理入口；应用数据可能包含在设备系统备份中，卸载或清除数据可能导致丢失。正式上线前需实现数据管理、迁移与隐私说明，不能承诺照片绝对不离开设备（用户主动识图时图片会发送到 DeepSeek）。
